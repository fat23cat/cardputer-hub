# Cardputer Hub Manuals

These manuals describe behavior that is currently supported by Cardputer Hub.
Planned capabilities are called out explicitly and must not be read as
available features.

## Manuals

* [Install Cardputer Hub](installing-firmware.md) — build and install the
  firmware from a fresh macOS or Ubuntu/Debian machine.
* [Device Guide](device-guide.md) — current features, controls, key
  combinations, diagnostics, and limitations.

The manuals must be updated in the same change that alters supported features,
controls, installation, updates, operation, or troubleshooting.
