# Home Micro 5 atlas

`micro5_home.h` contains monochrome masks at size 36, with a common 32×36
cell and proportional advances. The Home display label is uppercase; saved
host names are unchanged. It is generated by `scripts/generate_home_font.py`
using Pillow 12.3.0 and Micro5-Regular.ttf from fat23cat/codex-microputer-adv
revision `8f4ee82f504b3a3303b15c5ef5708139e05355c4`, path
`assets/fonts/audition/Micro5-Regular.ttf`.

Font SHA-256: `08a08c0d10129d2ecd869ff2f8914fcbf32487d3cbee3568b2a2957866dfdac8`.
The generator verifies this digest. The font's copyright and SIL Open Font
License 1.1 are in `OFL-micro5.txt` beside the derived masks.

Regenerate with `python scripts/generate_home_font.py <font.ttf> src/apps/shell/assets/micro5_home.h`,
then run `make format`.
